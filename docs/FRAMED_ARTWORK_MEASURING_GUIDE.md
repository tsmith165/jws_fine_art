# Framed artwork measuring guide

Use the finished outside dimensions whenever an artwork is framed. These measurements make the room visualizations and future packing decisions honest.

1. Place the artwork upright on a stable surface.
2. Measure the full width from the farthest outside edge of the frame to the opposite outside edge.
3. Measure the full height the same way. Include every visible part of the external frame.
4. Record inches to the nearest quarter inch. For example, `15.25` means 15¼ inches.
5. For a floater frame, measure the outside of the floater frame, not the painted panel inside it.
6. Do not include removable hanging wire, wall hooks, or temporary packing material.
7. If the frame is irregular, use the widest and tallest outside points.

Leave verification unchecked if you are using the provisional estimate or cannot physically measure the work yet. The artwork can remain public, but it will stay in Needs Attention until Jill confirms the measurement.
